# Client Guide (Non-Technical)

## What this platform gives your company

MT HRMS SaaS helps you:
- Onboard employees quickly and consistently.
- Run payroll with fewer errors and stronger visibility.
- Control access with enterprise-grade roles.
- View leadership-ready reports in one dashboard.
- Pay and manage subscription plans securely with Stripe.

## Main modules

1. **Dashboard**
   - Instant HR metrics: headcount, onboarding progress, payroll status.
2. **Employee Onboarding**
   - Hiring checklist automation and document tracking.
3. **Payroll**
   - Monthly/bi-weekly payroll runs, deductions and payslip history.
4. **User Management**
   - Fine-grained access control for HR, payroll, and leadership teams.
5. **Reports**
   - Workforce trends, payroll cost analytics, leave utilization.
6. **Billing**
   - Stripe-based subscription and invoice lifecycle.

## Why this is premium-grade

- Multi-tenant architecture for secure company data isolation.
- Fast UI optimized for frequent HR operations.
- Automated workflows that reduce operational load.
- Audit-ready data structure for compliance and governance.

## Typical rollout

1. Setup tenant and plan.
2. Import employees and users.
3. Configure onboarding templates and payroll rules.
4. Run first payroll in test mode.
5. Go live and monitor dashboard KPIs.
